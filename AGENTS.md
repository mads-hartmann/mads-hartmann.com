# Agent instructions

- Start with [README.md](README.md) for the repository overview and links to each component's README.
- Read the relevant component README before making changes. For shared footer changes, read [its README](sites/shared/footer/README.md); all three sites are affected.
- Use [Development](docs/development.md) for setup and validation, and [Deployment](docs/deployment.md) for infrastructure or deployment changes.
- Keep shared instructions in these human-readable documents and link to them here instead of duplicating them.

## Screenshots

- For changes to rendered page content or appearance, include screenshots in the final response and embed them in the pull request description. Documentation-only changes do not need screenshots.
- Build the affected sites and capture fresh desktop and mobile screenshots after the final UI changes. Include every affected site or page, and inspect the screenshots before sharing them.
- Keep screenshot files in ignored local build output or outside the repository. Never commit screenshots to Git.
- Upload screenshots as GitHub pull request attachments and embed their attachment URLs in the PR description. Do not use repository files, localhost URLs or ignored local paths as PR image links.
